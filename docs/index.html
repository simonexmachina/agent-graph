A local knowledge graph
for AI agents

AgentGraph indexes your Slack channels, Discord servers, Google Docs, Sheets, Drive, and Gmail into a searchable graph — queryable by CLI, web viewer, or MCP server.

View on GitHub Quick start
Browser extension → /observe (focus/blur events) ↓ Dwell evaluator (3 s threshold) ↓ Connector (Slack / Discord / Google / Gmail) ↓ SQLite knowledge graph (local, ~/.agentgraph/) ↙ ↘ CLI / Web viewer MCP server → AI agents
Features
Everything stays on your machine
🔒

Fully local

All data is stored in a SQLite database on your machine. Nothing is sent to any external server.

🔍

Hybrid search

Reciprocal Rank Fusion over vector similarity (sentence-transformers) and BM25 full-text search.

🤖

MCP server

Works with Claude Desktop and any MCP-compatible AI assistant out of the box.

🌐

Browser extension

Passively indexes content as you browse — no manual imports or file uploads needed.

🔗

Graph relationships

Entities, people, and edges: authored, posted_in, replied_to, mentions, references.

🧩

Pluggable connectors

New data sources can be added as separate Python packages via entry points.

Get started
Up and running in minutes
1

Install

Requires Python 3.12+ and uv.

git clone https://github.com/simonexmachina/agent-graph
cd agent-graph
uv sync --extra all
2

Authenticate

Run the interactive setup wizard to connect your data sources.

agentgraph onboard
3

Start the server

agentgraph serve
4

Install the browser extension

Build and load the unpacked extension in Chrome.

cd extension/agentgraph-extension
npm install && npm run build

Then go to chrome://extensions → Enable Developer mode → Load unpacked → select dist/.
