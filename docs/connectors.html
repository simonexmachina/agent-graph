Connector Author Guide

Build a connector to index any data source into AgentGraph. Connectors are plain Python packages that implement a single interface and register via an entry point.

Overview

A connector is a Python class that subclasses BaseConnector and implements fetch(). AgentGraph discovers connectors at runtime via Python entry points — no changes to the core package are needed.

Each connector is responsible for:

  • Fetching one resource (a channel, document, thread, etc.) from the source platform
  • Returning an EntityBatch with entities, people, and edges
  • Persisting a cursor so incremental sync works across polls
Boundary rule.

Connector-specific logic (auth, entity normalisation, mention parsing, user identity) must live in the connector package, not in the core agentgraph package. The core package provides the framework; connectors supply the platform knowledge.

BaseConnector interface

Required class attributes

AttributeTypeDescription
sourcestrUnique identifier used as the platform key (e.g. "slack", "gdocs")
entity_typestrPrimary entity type this connector produces (e.g. "Message", "Document")
poll_interval_secondsintHow often the background poller calls poll()

Required methods

MethodSignatureDescription
fetch async (resource_type, resource_id, meta?) → EntityBatch Fetch a single resource. Called for browser-dwell events and explicit agentgraph fetch commands. Must call upsert_batch() internally before returning.
poll async () → EntityBatch | None Incremental sync — fetch everything since the last cursor. Called on a timer by the background poller.
ingest async () → EntityBatch Bulk ingest — fetch all data within the retention window. Called once by agentgraph ingest <source>.

Skeleton

from agentgraph.connectors.base import BaseConnector, EntityBatch, ResourceType
from agentgraph.graph.upsert import upsert_batch


class MyConnector(BaseConnector):
    source = "myplatform"
    entity_type = "Document"
    poll_interval_seconds = 600  # 10 minutes

    async def fetch(
        self,
        resource_type: ResourceType,
        resource_id: str,
        meta: dict | None = None,
    ) -> EntityBatch:
        batch = EntityBatch()
        # ... populate batch ...
        await upsert_batch(batch)
        return batch

    async def poll(self) -> EntityBatch | None:
        # Load cursor, fetch new items, save cursor
        ...

    async def ingest(self) -> EntityBatch:
        # Fetch everything within the retention window
        ...
Data models

All models live in agentgraph.connectors.base.

EntityBatch

The container you build in fetch() / poll() / ingest().

FieldTypeDescription
entitieslist[EntityRecord]The primary entities in this batch
peoplelist[PersonRecord]People referenced in this batch
edgeslist[EdgeRecord]Relationships between entities or people

EntityBatch also provides a helper:

# Scan entity content for URLs and add stub entities + "references" edges
batch.add_stubs_from(entity)

Fetch policy

Use FetchPolicy to decide how much work to do for a given resource.

from agentgraph.connectors.base import FetchPolicy

# Load the existing entity's last_synced_at timestamp
policy = await FetchPolicy.for_entity(platform=self.source, platform_entity_id=resource_id)

if policy == FetchPolicy.FIRST_VISIT:
    # Entity is new — full fetch
    ...
elif policy == FetchPolicy.INCREMENTAL:
    # Entity exists but is stale — fetch only new items
    ...
elif policy == FetchPolicy.FRESH:
    # Entity was synced recently — skip or return cached
    return EntityBatch()
ValueMeaning
FIRST_VISITNo prior sync record — do a full fetch
INCREMENTALSynced before but stale — fetch only what's changed since the cursor
FRESHSynced recently — no fetch needed; return an empty batch
Optional hooks

Override these classmethods / instance methods on your connector to integrate with AgentGraph features.

current_user_id optional

Return a canonical identifier for the authenticated user. Used by agentgraph query --mine to filter entities to those authored by the current user.

# Example — Google connectors return the OAuth email
@classmethod
def current_user_id(cls) -> str | None:
    return get_user_email()  # returns None if not authenticated

# Example — Slack connector returns "slack:{user_id}"
@classmethod
def current_user_id(cls) -> str | None:
    creds = load_credentials()
    return f"slack:{creds.user_id}" if creds else None

normalise_fetch_id optional

Map a stored (resource_id, entity_type) pair to the fetchable (resource_id, ResourceType) that fetch() expects. Override when your stored IDs differ from fetch IDs (e.g. Discord stores channel_id:message_id but fetches by channel_id).

# Default implementation (works for most connectors)
def normalise_fetch_id(
    self, resource_id: str, entity_type: str
) -> tuple[str, ResourceType]:
    type_map = {
        "Document": "document", "Folder": "folder",
        "Channel": "channel", "Message": "message",
    }
    return resource_id, type_map.get(entity_type, "document")

run_auth_flow optional

Classmethod that opens an auth flow when called by agentgraph auth <source> and agentgraph onboard. If omitted, those commands will skip your connector.

@classmethod
def run_auth_flow(cls) -> None:
    # Open browser, prompt for token, write to ~/.agentgraph/
    ...

onboard_prompt / auth_description / auth_label optional

Class attributes that customise the agentgraph onboard wizard UI. If auth_label is set, connectors sharing the same label appear as a single onboarding step (useful for multi-connector platforms like Google).

auth_label = "google"          # groups gdocs, gsheets, gdrive, gmail together
auth_description = "Google (Docs, Sheets, Drive, Gmail)"
onboard_prompt = "Set up Google integration?"
Auth integration

AgentGraph does not prescribe an auth mechanism. Connectors store credentials wherever makes sense — all built-in connectors use ~/.agentgraph/:

from agentgraph.config import CONFIG_DIR

# Write a token
token_file = CONFIG_DIR / "myplatform_token.json"
token_file.write_text(json.dumps(token_data))

# Read it back
if token_file.exists():
    data = json.loads(token_file.read_text())

CONFIG_DIR is ~/.agentgraph/ by default and is always local to the user's machine — never synced externally.

Packaging & distribution

Connectors are discovered via a named entry point group. Any installed package that declares a connector in this group will be loaded automatically when AgentGraph starts.

pyproject.toml

# In your connector package's pyproject.toml
[project]
name = "agentgraph-connector-myplatform"
# ...

[project.entry-points."agentgraph.connectors"]
myplatform = "agentgraph_connector_myplatform:MyConnector"

Multiple connectors from the same package are supported — just add more entries:

[project.entry-points."agentgraph.connectors"]
myplatform-docs  = "agentgraph_connector_myplatform:DocsConnector"
myplatform-tasks = "agentgraph_connector_myplatform:TasksConnector"

Development install

# Install your connector package in editable mode alongside agentgraph
uv pip install -e packages/agentgraph-connector-myplatform

After install, run agentgraph onboard to authenticate, then agentgraph serve — your connector will be polled automatically.

Minimal example

A complete, working connector that indexes a fictional REST API:

# agentgraph_connector_myplatform/__init__.py
from __future__ import annotations

import httpx
from agentgraph.config import CONFIG_DIR
from agentgraph.connectors.base import (
    BaseConnector, EntityBatch, EntityRecord, FetchPolicy, ResourceType
)
from agentgraph.graph.upsert import upsert_batch

_TOKEN_FILE = CONFIG_DIR / "myplatform_token.txt"


class MyConnector(BaseConnector):
    source = "myplatform"
    entity_type = "Document"
    poll_interval_seconds = 600
    auth_description = "My Platform"
    onboard_prompt = "Set up My Platform integration?"

    @classmethod
    def run_auth_flow(cls) -> None:
        token = input("Paste your API token: ").strip()
        _TOKEN_FILE.parent.mkdir(parents=True, exist_ok=True)
        _TOKEN_FILE.write_text(token)
        print("Token saved.")

    def _token(self) -> str | None:
        return _TOKEN_FILE.read_text().strip() if _TOKEN_FILE.exists() else None

    async def fetch(
        self, resource_type: ResourceType, resource_id: str, meta: dict | None = None
    ) -> EntityBatch:
        policy = await FetchPolicy.for_entity("myplatform", resource_id)
        if policy == FetchPolicy.FRESH:
            return EntityBatch()

        async with httpx.AsyncClient() as client:
            resp = await client.get(
                f"https://api.myplatform.example/docs/{resource_id}",
                headers={"Authorization": f"Bearer {self._token()}"},
            )
        doc = resp.json()

        batch = EntityBatch()
        batch.entities.append(EntityRecord(
            entity_type="Document",
            platform="myplatform",
            platform_entity_id=resource_id,
            title=doc["title"],
            content=doc["body"],
            metadata={"author": doc.get("author")},
        ))
        await upsert_batch(batch)
        return batch

    async def poll(self) -> EntityBatch | None:
        # Minimal: return None to skip polling until you implement cursors
        return None

    async def ingest(self) -> EntityBatch:
        # Bulk ingest — implement when you need it
        return EntityBatch()
