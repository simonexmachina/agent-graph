Privacy Policy

Last updated: May 2025

Short version: AgentGraph is a local tool. Your data stays on your machine. Nothing is sent to any external server by AgentGraph itself.

What is AgentGraph?

AgentGraph is an open-source application that you install and run locally on your own computer. It indexes content from connected data sources (Slack, Discord, Google Docs, Google Sheets, Google Drive, Gmail) into a local SQLite database, and makes that data searchable via a CLI, web viewer, and MCP server for use with AI assistants.

Data collection and storage

AgentGraph does not operate any servers or cloud infrastructure. When you run AgentGraph:

  • All indexed content is stored in a SQLite database on your local machine (by default at ~/.agentgraph/agentgraph.db).
  • Credentials (OAuth tokens, API keys) are stored in ~/.agentgraph/credentials.json on your local machine.
  • No data is transmitted to the developers of AgentGraph or any third party controlled by AgentGraph.

Google API usage

AgentGraph uses the following Google APIs to read content on your behalf:

  • Google Docs API — to read document content
  • Google Sheets API — to read spreadsheet content
  • Google Drive API — to list and access files in Drive
  • Gmail API — to read email threads in your inbox

AgentGraph's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically:

  • Data obtained from Google APIs is used only to provide the core functionality of AgentGraph: building and querying a local knowledge graph for your personal use.
  • Google user data is not used for advertising, is not sold to third parties, and is not used to train machine learning models.
  • Google user data is not shared with humans except as necessary to provide the service you requested (i.e., displaying it to you in the AgentGraph interface).
  • All Google API data is stored locally on your machine and is not transmitted to AgentGraph developers or any third-party server.

Third-party API calls

AgentGraph makes outbound API calls directly from your machine to the services you have authenticated with (Google, Slack, Discord). These calls are made under your own credentials and are subject to those services' own privacy policies. AgentGraph does not intermediate or log these requests.

If you use the MCP server integration, your AI assistant (e.g. Claude Desktop) will receive content from your local AgentGraph database. This is governed by the privacy policy of the AI assistant you have chosen.

Open source

AgentGraph is fully open source. You can review exactly what the software does at github.com/simonexmachina/agent-graph. There are no hidden network calls or telemetry.

Children's privacy

AgentGraph is a developer tool not directed at children under 13. We do not knowingly collect personal information from children.

Changes to this policy

If this policy changes materially, the updated version will be published at this URL with a revised date.

Contact
