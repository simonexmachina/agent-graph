Command reference

The CLI and MCP server expose the same graph operations. Use the CLI directly for local work, or connect an MCP client to run the same actions from an assistant.

Shared surface: search, query, fetch, poll, and connector inspection are the same operations whether you trigger them via agentgraph or via MCP.

Query

agentgraph search

Hybrid semantic and lexical search across the local graph.

agentgraph search "project kickoff notes" --type Document --limit 10 --json

agentgraph query

Filter entities by type, ownership, time window, and attachment presence.

agentgraph query --type Message --filter platform=slack --since 24h --mine --limit 20

agentgraph get

Return one entity by UUID, UUID prefix, or platform reference.

agentgraph get abc123ef --json
agentgraph get slack/C0J2L41FT --resolve

agentgraph edges

List connected edges for one entity, filtered by direction and edge type.

agentgraph edges abc123ef --direction both --type mentions --json

agentgraph traverse

Walk outward from an entity across graph edges.

agentgraph traverse abc123ef --depth 2 --resolve --json

Fetch

agentgraph fetch

Trigger a connector fetch by source and platform-specific identifier.

agentgraph fetch slack C0J2L41FT
agentgraph fetch gdocs 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms

agentgraph fetch-entity

Re-fetch a known entity by internal UUID.

agentgraph fetch-entity abc123ef-9d6b-4bbe-b5ab-200faecb70e9 --json

Sync

agentgraph poll

Run background polling immediately for one connector or all installed connectors.

agentgraph poll
agentgraph poll slack
agentgraph poll gmail

agentgraph ingest

Run a one-shot ingest across the connector’s historical retention window.

agentgraph ingest gmail

Connector status

agentgraph connectors

List installed connectors, their auth status, URL patterns, and whether they poll.

agentgraph connectors
agentgraph connectors --json

Authentication

agentgraph onboard

Walk through auth setup for every installed connector.

agentgraph onboard

agentgraph auth

Authenticate a specific connector directly.

agentgraph auth google
agentgraph auth slack
agentgraph auth discord

Server

agentgraph serve

Start the local HTTP server, connector pollers, and graph viewer.

agentgraph serve
agentgraph serve --reload

MCP

agentgraph mcp-config

Print the client configuration snippet for Claude Desktop, Claude Code, and remote MCP guidance for ChatGPT developer mode.

agentgraph mcp-config

agentgraph mcp-serve

Run the MCP server directly over stdio, SSE, or streaming HTTP.

agentgraph mcp-serve
agentgraph mcp-serve --transport sse --port 8808
agentgraph mcp-serve --transport streamable-http --port 8808
