Command Reference

Every operation below is available both as a CLI command and as an MCP tool — the same interface whether you're running it in a terminal or asking an AI agent to do it.

CLI or MCP — your choice. The agentgraph CLI and MCP server expose identical operations. Use the CLI directly in a terminal, or configure the MCP server to give any compatible AI assistant (Claude Desktop, Claude Code, etc.) direct access to your knowledge graph.

Query
agentgraph search Semantic search across all entities 
agentgraph search "project kickoff notes" --type Document --limit 10 --json
QUERY
Search query (required)
--type
Filter by entity type: Message, Document, Channel, Thread, Spreadsheet, Folder, Person
--limit N
Maximum results (default: 10)
--json
Output as JSON
agentgraph query Filter entities by type and metadata 
agentgraph query --type Message --filter platform=slack --since 24h --mine --limit 20
--type
Entity type (required)
--filter key=value
Metadata filter; may be repeated
--since
Time window: 30m, 12h, 7d, or ISO timestamp
--mine
Filter to entities authored by the authenticated user
--has-attachments
Only return messages with file attachments
--order-by
last_accessed (default), created_at, updated_at
--limit N
Maximum results (default: 50)
--json
Output as JSON
agentgraph get Fetch full details for an entity 
agentgraph get abc123ef --json
agentgraph get slack/C0J2L41FT --resolve

Accepts a full UUID, UUID prefix, or platform reference (platform/entity_id). --resolve fetches stub entities from their source before returning.

agentgraph edges List edges for an entity 
agentgraph edges abc123ef --direction both --type mentions --json
--type
Filter by edge type: authored, posted_in, replied_to, mentions, references
--direction
in, out, or both (default: both)
--json
Output as JSON
agentgraph traverse Walk the graph from a starting entity 
agentgraph traverse abc123ef --depth 2 --resolve --json
--depth N
Maximum hops from the starting entity (default: 2)
--resolve
Fetch any stub entities encountered
--json
Output as JSON
Fetch
agentgraph fetch Trigger a connector fetch for a platform entity 
agentgraph fetch slack C0J2L41FT
agentgraph fetch gdocs 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms

Resets the entity's sync timestamp and re-fetches from the source, regardless of freshness policy.

agentgraph fetch-entity Re-fetch an entity by its internal UUID 
agentgraph fetch-entity abc123ef-9d6b-4bbe-b5ab-200faecb70e9 --json
Sync
agentgraph poll Trigger a background poll for one or all connectors 
agentgraph poll          # all connectors
agentgraph poll slack    # Slack only
agentgraph poll gmail

Polls for new content since the last sync. Equivalent to what the scheduler runs automatically in the background.

agentgraph ingest Bulk ingest all data within the retention window 
agentgraph ingest gmail   # all mail (not just inbox) within 90 days

One-shot full-history import. Useful on first setup or after a long gap. The server returns immediately and logs progress to /tmp/agentgraph.log.

Server
agentgraph serve Start the AgentGraph backend server 
agentgraph serve
agentgraph serve --reload   # auto-restart on code changes (development)

Starts the HTTP server on http://localhost:8765. The web graph viewer is available at /viewer. Logs to /tmp/agentgraph.log.

MCP
agentgraph mcp-config Print the MCP config snippet for your AI client 
agentgraph mcp-config

Outputs a ready-to-paste JSON block with the correct path to the agentgraph binary on your machine. Add it to:

Claude Desktop
~/Library/Application Support/Claude/claude_desktop_config.json
Claude Code (global)
~/.claude/mcp.json
Claude Code (project)
.claude/mcp.json in your project root
Example output
{
  "mcpServers": {
    "agentgraph": {
      "command": "/path/to/.venv/bin/agentgraph",
      "args": ["mcp-serve"]
    }
  }
}

No additional configuration is needed — the MCP server reads the same settings as the CLI (database path, connector credentials, etc.).

agentgraph mcp-serve Start the MCP server directly (stdio transport) 
agentgraph mcp-serve

Usually invoked by the MCP client automatically — you don't need to run this manually.

Auth
agentgraph onboard Interactive setup wizard 
agentgraph onboard

Walks through authentication for each installed connector in sequence. The recommended way to get started.

agentgraph auth Authenticate a specific connector 
agentgraph auth google     # Google OAuth2 — Docs, Sheets, Drive, Gmail
agentgraph auth slack      # Slack cookie credentials
agentgraph auth discord    # Discord bot token
